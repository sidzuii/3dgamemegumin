# Мегумин: Дорога приключений

Браузерная anime fantasy action RPG на Three.js. Мегумин приезжает в Аксель — город начинающих
искателей приключений, — вступает в гильдию, берёт заказы, знакомится с жителями и постепенно
выходит на след упавших звёзд. Рокси Мигурдия появляется только в главе 4 и присоединяется
после собственной сюжетной линии.

---

## 1. Быстрый старт

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # production-сборка в dist/
npm run preview    # просмотр сборки: http://127.0.0.1:4173
```

**Игра как программа для Windows (без установки и без сервисов):** `npm run portable` собирает `release/Megumin`
(на Windows ещё и `release/Megumin.zip`): `Play.bat`, `README.txt` и `app/` (`serve.ps1` — маленький веб-сервер на встроенном
Windows PowerShell, `megumin.ico`, `game/` — сборка). Первый запуск `Play.bat` создаёт ярлык «Мегумин» с иконкой на рабочем
столе и в «Пуске»; ярлык открывает игру в своём окне Edge/Chrome (режим приложения, без адресной строки, свой профиль
`%LOCALAPPDATA%\Megumin\browser` = свои сохранения), консоль скрыта, закрыл окно — сервер выключился.
`serve.ps1 -Server` — только сервер в видимой консоли (для другого браузера).

Node.js 18+, браузер с WebGL2. Для пересборки ассетов — Blender 4.x (раздел 9).
Отладка: `window.__game` (`__game.rpg.state`, `__game.rpg.quests.active()`, `__game.npcs.list`,
`__game.inventory.add('herb', 5)`, `__game.travel('square')`, `__game.rpg.state.time.minutes = 22*60`).

## 4. Сюжет и задания

Сюжет — **сценарный пакет** `docs/story/` (главы 0–10, побочные истории B01–B23, правила и переменные; см.
`docs/story/00_start.md`). Реплики лежат в `src/data/story/clips.js` под ID пакета (`A00_001`…), сцены —
программы над этими ID (`src/data/story/*.js`, язык `dsl.js`), так что текст не копируется и озвучка потом
ложится на те же ID. Переменные пакета (`ROXY_TRUST`, `BERNARD_PROMISE`…) — `state.vars` (`story/vars.js`).
Проверка: `node tools/story/check.mjs` (граф сцен, неизвестные условия/эффекты/квесты, покрытие реплик).
Старое сохранение (до пакета) перезапускает сюжет и сохраняет персонажа (`STORY_REV` в `rpg/State.js`).

Приёмка: `node tools/combat/tests.mjs` (BT01–BT15, BT19, BT22–BT23 и числовые правила; выходит с кодом 1 при провале).
Управление: ЛКМ — серия посохом, ПКМ — защита, Пробел/V — уклон, Q/E — средние навыки, R/F — заклинания (ЛКМ подтверждает, ПКМ отменяет), Tab — смена героини, T — приказ напарнице, СКМ — цель, E (удерживать) — поднять упавшую героиню, 3/4/5 — зелья. Вкладка меню «Бой» (K): тряска камеры, яркие вспышки, автопереключение после Explosion, средние навыки напарницы, справка по навыкам (настройки — `localStorage megumin-combat`).
Навыки Мегумин открывает сюжет (`combat/unlocks.js`: Выпад — после учебного боя у Брана, Отбив — после первого заказа, Пролом — после ранга E); Рокси знает весь набор с момента вступления в отряд.
Сустав каменного стража (`type.joint` в `Enemy.js`) открыт в восстановлении после тяжёлого удара и при оглушении: защита падает, урон ×1,8 (янтарное свечение + значок ✦) — так ритуал (A25) проходится одним посохом.
Плотность частиц зависит от пресета графики (`PRESETS.fx` в `core/Quality.js`, `vfx.density`): формы областей, телеграфы и сигналы не меняются.
Расчёт: `урон = коэф × (A или S) × 100/(100+защита)`, компоненты считаются отдельно и округляются один раз; взрывное попадание по намокшей цели +10% и снимает Намокание.
Реплики боя `CB_*` — `src/data/story/combatClips.js` (генерируется `node tools/combat/gen_clips.mjs` из `docs/combat/Реплики_для_боевки.txt`); теги заклинаний `explosive` / `story_demolition` проверяют сюжетные правила (запрет в Акселе и руинах, завал открывает только Explosion).

### Порядок кадра (`Game._frame`)
окна (пауза: диалог, торговля, меню, книга) → ввод боя → игрок → ядро боя (фикс. шаг) и спутница → враги → снаряды →
RPG (часы, квесты, события, сохранение) → NPC → регионы → день/ночь → мир → камера → взаимодействие → VFX → HUD.

## 6. Как расширять

- **Новый регион:** запись в `REGIONS` (+ `FLATS`/`HILLS`/`ROADS` при необходимости), функция постройки
  в `world/build/Countryside.js`, точки (`W.spot`) для NPC и квестов, лагеря врагов в `CAMPS`.
- **Новый NPC:** запись в `data/npcs.js` (внешность `look`, расписание по точкам, `talk` → диалоги).
- **Новый квест:** запись в `data/quests.js` (стадии, цели, `target`, награды, `requires`) + диалоги
  с эффектами `{ startQuest }` / `{ advance }`.
- **Магазин / рецепт:** `data/shops.js`. **Предмет:** `data/items.js`. **Ресурс:** `data/resources.js`.
- **Мировое событие:** блок в `rpg/WorldEvents.js` (условие, жизненный цикл, флаг награды).
- **Баланс:** `MOVE`, `STAMINA`, `ATTACKS`, `EXPLOSION`, `VOLLEY`, `TYPES`, `XP_TABLE`, цены в `ITEMS`.

## 6а. Редактор карты

Запуск: `npm run dev`, затем http://127.0.0.1:5173/?editor (или кнопка «Редактор карты» на стартовом экране).

- **Что редактируется:** все места, построенные кодом и помеченные `world.group(id, …)`:
  - дома, лавки, гильдия, таверна, храм, склеп, прилавки, фонари, колодцы;
  - фермы, мельница, дома и часовня Ольховки;
  - лагеря, башня, вход в шахту, руины и дальние регионы.

  Их можно двигать, поворачивать, масштабировать, поднимать и удалять. Вместе с ними после перезапуска переезжают места NPC, квестовые предметы, сундуки, свет и коллизии.
- **Новые объекты** берутся из палитры слева: дом (размер, этажи, цвет крыши, стены), прилавок, фонарь, скамейка, колодец, фургон, забор, деревья, кусты, камни, палатка, костёр, бочка, ящик, стог, а также любая модель Kenney (поиск по имени).
- **Управление:**
  - ПКМ + мышь — осмотр, WASD — полёт, E/Q — выше/ниже, колесо — ближе/дальше;
  - ЛКМ — выбрать, тащить выбранное — переместить;
  - R / Shift+R — поворот на 15° (Alt — на 1°), PgUp/PgDn — высота, +/− — масштаб;
  - Del — удалить, Ctrl+D — копия, F — показать, G — сетка 0,5 м;
  - Ctrl+Z / Ctrl+Y — отмена и повтор, Ctrl+S — сохранить.
- **Сохранение** пишет `public/data/placements.json` (предыдущая версия — `placements.backup.json`); игра применяет его при сборке мира.
  - `overrides` — изменения встроенных мест (`x`, `z`, `rot`, `s`, `dy` или `deleted`);
  - `added` — поставленные объекты.
- **Не редактируется:** дороги, река, рельеф, леса (их генератор обходит постройки и сам подстраивается) и подземелье. Стена Акселя — группы `axel_wall`, `gate_*`, `tower_*`; улицы — `axel_streets`; дома — `axel_<район>_<n>`.
- **Версия раскладки:** `placements.json` хранит `"layout": 2`; файл от старой карты игнорируется (копия старого — `placements.v1.json`).
- **Код:** `src/editor/Editor.js`, `src/world/build/Placements.js`, `World.group()`; точка сохранения — плагин в `vite.config.js`.

## 7. Сохранения

`localStorage['megumin-save-v2']`: позиция, HP/мана/уровень, инвентарь и экипировка, эрисы, квесты,
флаги сюжета, гильдия, отношения, сундуки, открытые регионы, туман карты, ресурсы, магазины, события, время.
Автосохранение каждые 30 с и сразу после важных шагов. Повреждённый файл → новая игра с уведомлением.
Сохранения, где глава 5 уже закрыта, при загрузке получают «Проход к Айнстрею» (решения и флаги сохраняются; `ENDING` ничего не решает).
Старое сохранение `megumin-save-v1` переносится (эрисы и предметы), история начинается с пролога.
«Новая игра» на стартовом экране удаляет сохранение (с подтверждением).

**Жители** (`npc/People.js`) собираются из частей наряда (голова, тело, ноги, обувь, рюкзак/меч) в один
скин-меш с цветами в вершинах (перекраска по имени материала, `model` в `data/npcs.js`). Анимации — те же
mocap-клипы UAL, перенесённые на скелет пака (`MAPS.qp`); сидение — поза ног поверх idle (`NPC._sitPose`).

**Наборы Kenney** (`world/KitLibrary.js`): деталь `'набор/модель'` ставится через `Frame.kit()` / `world.addKit()`
в общие батчи мира. Палитра перекрашивается на загрузке (тёмные балки, кремовая штукатурка, коричневые доски,
чугун и серый камень у кладбища; варианты кровли `@red|blue|green|brown|slate|purple|straw`); природа —
в зелень долины. Из Kenney — прилавки с едой, фонари, заборы, скамейки, цветы, грибы, пни, палатки, костры,
мебель и посуда в интерьерах, кладбище у часовни Ольховки и склеп за храмом Акселя (задел главы 5).

**Дома** (`house()` в `build/Kit.js`) собираются из модулей Quaternius Medieval Village: стены 2 м (камень /
штукатурка / фахверк), вставные окна со ставнями, двери, угловые балки, готовые черепичные крыши и
фронтоны, подогнанные под размер дома; печные трубы. **Деревья и кусты** — Quaternius Stylized Nature,
рисуются инстансингом с двумя уровнями детализации (`world/TreeField.js`: полная модель с тенью до 42 м,
облегчённая — до 330 м, отсечение по полю зрения). **Новые враги:** Пуглин (логово гоблинов, Чаща) и Бес
(Чаща, Багровое ущелье, заброшенный посёлок); скелеты KayKit — воин, разбойник и прислужник (заброшенный
посёлок Старой шахты, комната шахтёров в подземелье). Стена и башни Акселя — геометрия Kenney castle-kit с камнем Medieval Village (`cityWall()` в `Kit.js`). Процедурными остались мосты, мельница,
колодец, фургоны и рельеф.
Ретаргет строится от bind-позы скелета; ноги в покое ставятся IK ровно; голова стабилизируется;
посох держится в кулаке (`rigUtils.js`: `gripStaff`, `StaffHold`, `solveTwoBone`).

"C:/Program Files/Blender Foundation/Blender 4.5/blender.exe" -b --python tools/blender_rig_demon.py -- <in.glb> <out.glb>
