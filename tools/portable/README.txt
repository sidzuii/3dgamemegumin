Мегумин: Дорога приключений

1. Распакуй архив целиком (правой кнопкой -> «Извлечь всё»). Из архива не запускай.
2. Первый раз дважды щёлкни Play.bat. Он создаст ярлык «Мегумин» на рабочем столе и в меню «Пуск» и откроет игру.
   Если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее» -> «Выполнить в любом случае».
3. Дальше запускай игру с ярлыка «Мегумин». Игра открывается в своём окне; F11 — во весь экран.
   Закрыл окно — игра выключилась.

Сохранения лежат в %LOCALAPPDATA%\Megumin (не удаляй эту папку, если хочешь сохранить прогресс).
Если папку с игрой перенесёшь в другое место — ещё раз запусти Play.bat (ярлык обновится).
Нужен Microsoft Edge (есть в каждой Windows 10/11) или Google Chrome.
