# Каменный уступ (D03–D09): как устроен

Реализация главы 6 (`docs/ainstrey/06_Глава_Айнстрея.md`). Здесь только устройство уровня и состояния; сюжет и реплики лежат в `src/data/story/chD1.js`, квест — `ainstrey_road` в `src/data/quests.js`.

## Место

Тракт от Почтового подъёма идёт по ущелью между двумя скальными поясами (`LEDGE_CLIFFS` в `src/world/AinstreyPlan.js`, высота `cliffHeight` в `src/world/Terrain.js`).
Пояса — земля, а не декор: плоская вершина и склон круче проходимого (MAX_SLOPE 48°), поэтому долина Почтового подъёма замкнута и завал — единственный путь вперёд. Пояса ведут от края листа
до восточного конца ущелья, а площадка вокруг завала выровнена (`LEDGE_FLAT`), чтобы всё задание строилось на одном уровне.

Система координат уступа (`LEDGE` в плане, `Frame` в `build/AinstreyLedge.js`): начало на дороге в середине завала, **f** — вдоль дороги к столице, **l** — влево (северо-запад, высокая стена), y вверх.

| f | l | что |
|---|---|---|
| −60…−30 | −12…+14 | площадка бригады: палатки, костёр, стол с планом, стойка с инструментом, колокол для телег; Дорен `ledge_doren`, Нэра `ledge_nera` |
| −26 | −14…+14 | сигнальные шесты (визуальная граница, невидимой стены нет) |
| −30…+2 | +13 | лестница-галерея вдоль северной стены (22°), посадочная площадка с панелью поста (f −14), мосток к верхней площадке |
| −0.5…8.5 | +23…+29 | каменный бак верхнего кармана на вершине северного пояса; затвор `pocket_gate` |
| +10 | +7…+9 | старая лебёдка и цепь к валуну; косая плита опирается на северный склон |
| +16 | −2 | валун; кучи обломков поперёк всей долины (f +18…+26) |
| +2…+30 | −34…−14 | подготовленный карман (закоулок у южной стены, обшитый брёвнами); устье f +14…+20 |
| +40 | −5, +4 | две отметки старого поста (пластины, светятся янтарём, пока пост жив) |
| +46 | −16…+16 | барьер бригады (козлы, верёвка, знак): стоит после основной расчистки до начала проверки телег |
| +37 | −4…+4 | настил над водоотводом: сломан → починен |

## Состояния

`world.ledge.sync(flags, vars, instant)` вызывается из `RPG._syncProps` при любом изменении флага. Видимое состояние и коллизия (`world.dynamicColliders`, цилиндры; статический BVH не меняется) целиком выводятся из флагов и переменных, поэтому сохранение/загрузка/смена суток ничего не «возвращают».

| состояние | условие | валун | плита | кучи | барьер |
|---|---|---|---|---|---|
| завал | флаги не стоят | на дороге | наклонена | поперёк | нет |
| основная расчистка | `ledge_main_cleared` | Взрыв: осколки в кармане; лебёдка: в кармане | Взрыв: наклонена и подпёрта; лебёдка: лежит в кармане | остаются три обломка | есть до `ledge_barrier_open` |
| уборка | `ledge_chain_off`, `ledge_debris_a/b/c`, `ledge_deck_fixed` | | | обломков нет | |
| дорога открыта | переменная `AINSTRAY_ROAD_OPEN` | | | по краям лежат только сложенные камни | нет |

Анимации (только когда флаг меняется в игре, не при загрузке): Взрыв — вспышка, осколки по дуге в карман, тряска камеры; лебёдка — плита ползёт 4 с вместе с валуном, пыль, тряска; слив — вода в баке опускается за 9 с, 22 с бежит по канаве или из служебного стока.

## Задание `ainstrey_road`

luna → nera → edmund → sack → doren → survey → drain_talk → (p_ditch | p_service) → brace → method → (p_expl | p_winch) → (g_off | g_fight) → cleanup → carts_empty → carts_loaded → act → view → fork → mills_talk → mills_task → dam.

* Награда 200 эрис выдаётся один раз — в `onDone` стадии `act`; повторный разговор с Нэрой даёт только реплику.
* Пост охраны: панель `road_post_panel` (нужен прибор Эдмунда) доступна со стадии `survey` до выбора способа; `ROAD_POST_DISABLED` пропускает бой (`g_off`).
* Стражи (`g_fight`): волна `road_guards` — на отметках загорается руническая вспышка, через 3,5 с стражи встают на них; к лежащей Мегумин они не заходят со спины: отметки в 40 м впереди от места Взрыва.
* Лебёдка: `winch_turn_a` (Мегумин) → залп Рокси на край плиты → `winch_turn_b` → залп → триггер `winch_safe`: плита идёт, когда обе героини за шестами.
* Телеги: колокол у шестов запускает `world.ledge.runCart('empty'|'loaded')`; повозка идёт по `cartPath`, на конце срабатывает флаг и реплики D09a/D09b.
