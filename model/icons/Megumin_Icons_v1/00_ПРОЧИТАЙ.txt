MEGUMIN GAME — ИКОНКИ v1

В наборе 80 иконок:
— 64 предмета из текущего src/data/items.js;
— 8 боевых приёмов Мегумин и Рокси;
— 8 значков интерфейса: здоровье, мана, выносливость, сумка, задания, карта, ремесло, настройки.

ЧТО ОТКРЫТЬ
Распакуй весь архив в одну папку и открой preview.html в браузере.
Там можно переключать фон, размер иконок и категории.

PNG — АТЛАСЫ
items_01.png … items_04.png: по 16 предметов в каждом.
skills_ui.png: навыки и интерфейс.
На каждом листе сетка 4 × 4; видимых линий сетки нет.
Точные границы каждого предмета уточнены отдельно в icons.json. Для отображения бери эти прямоугольники, а не деление картинки на четыре равные части.
Прозрачность настоящая, через альфа-канал PNG. Исходные изображения не пересохранены и не обрезаны.
Это пять листов, а не 80 отдельных PNG. Их можно использовать через координаты, не разрезая.

ПРИВЯЗКА К ИГРЕ
icons.json содержит ID из каталога игры, названия, файл атласа и прямоугольник каждой иконки.
Начало координат — левый верхний угол. Строки и столбцы нумеруются с нуля.
Параметры размера атласа записаны по фактическим PNG; используй их, а не предполагаемое разрешение.

ПОДКЛЮЧЕНИЕ
В integration лежат вспомогательный модуль IconAtlas.js и CSS для существующего браузерного проекта.
Это подготовленные файлы для интеграции. Они ещё не внесены в игру на рабочем столе.
Задание Claude с конкретными местами подключения — в CLAUDE_подключить_иконки.txt.

СТИЛЬ
Рисованное фэнтези: тёплые контуры, выразительные формы, красная магия Мегумин и синяя магия Рокси.
Рамки редкости и количество предметов продолжает рисовать интерфейс игры.

КАК ПОЛУЧЕНЫ
Изображения созданы встроенным image_gen. Полные запросы и порядок ячеек сохранены в prompts.json.
Проверены альфа-канал, заполнение всех 80 ячеек и покрытие 64 ID предметов.
В настоящей игре отображение ещё нужно проверить после подключения.
