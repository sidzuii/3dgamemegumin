# Две фэнтезийные книги

Созданы две самостоятельные объёмные модели по референсам: раскрытая книга с изогнутыми кремовыми страницами и закрытая книга с бордовой кожаной обложкой. У обеих моделей есть отдельная геометрия страниц, корешка и латунных накладок. Предыдущие файлы персонажа сохранены без изменений.

## Файлы

| Файл | Назначение |
| --- | --- |
| [OpenBook/OpenBook.blend](OpenBook/OpenBook.blend) | Раскрытая книга в Blender, материалы и текстуры упакованы внутрь |
| [OpenBook/OpenBook.glb](OpenBook/OpenBook.glb) | Раскрытая книга для Three.js и других glTF-просмотрщиков, текстуры встроены |
| [OpenBook/OpenBook.fbx](OpenBook/OpenBook.fbx) | Раскрытая книга для импорта в другие 3D-приложения |

## Геометрия и материалы

Раскрытая книга содержит **23 384 треугольника**, закрытая — **11 692 треугольника**. Слои бумажного блока, изгиб страниц, уголки и застёжки выполнены геометрией. На каждом листе раскрытой книги расположена 21 строка декоративных штрихов с небольшими промежутками и тонкая рамка с ромбами. Это орнаментальные линии, а не читаемый текст.

Штрихи и рамки повторяют кривизну поверхности и остаются отдельной объёмной геометрией, поэтому их чёткость не зависит от разрешения атласа. Обложка и бумага имеют UV-развёртку. Физические материалы кожи, бумаги и латуни созданы процедурно в Blender и запечены в карты PBR:

| Карта | Размер | Данные |
| --- | --- | --- |
| `*_BaseColor_4K.png` | 4096 × 4096 | Цвет, sRGB |
| `*_Roughness_2K.png` | 2048 × 2048 | Шероховатость, Non-Color |
| `*_Metallic_2K.png` | 2048 × 2048 | Металличность, Non-Color |
| `*_Normal_2K.png` | 2048 × 2048 | Нормали в пространстве касательных, Non-Color |
| `*_AO_2K.png` | 2048 × 2048 | Окклюзия, Non-Color |

Вместо `*` используется имя модели: `OpenBook` или `ClosedBook`. Модели созданы из настоящей 3D-геометрии; плоских изображений референса на подложке в них нет. Для производства этих ассетов не использовалась генерация изображений.

## Масштаб и использование

Единицы Blender — метры. Книги расположены по центру X/Y, их нижняя точка находится на Z = 0. У закрытой книги ширина около 32 см, высота около 44 см, толщина около 8,5 см; металлические накладки немного расширяют общий габарит. Точные границы каждой модели записаны в её `asset_manifest.json`.

Для Three.js загружай соответствующий `.glb` через `GLTFLoader` и добавляй `gltf.scene` в сцену. glTF использует ось Y вверх; преобразование из координат Blender выполнено при экспорте. При необходимости меняй масштаб корневой группы целиком — текстуры и детали сохранят взаимное положение. Для отображения PBR-материалов нужны освещение или окружение сцены.

Это две статические модели. Анимация раскрытия и риг в данный комплект не входят.

## Предпросмотр и исходники

В папке каждой книги доступны PNG-рендеры `*_Preview_ThreeQuarter.png`, `*_Preview_Top.png`, `*_Preview_Back.png`, а также круговой обзор `*_Turntable.mp4`.

Скрипты сборки находятся в `work/`: общий запуск `build_books.py`, материалы и экспорт в `book_common.py`, геометрия в `build_open_book.py` и `build_closed_book.py`. Для повторной сборки нужен Blender с Python; внешние модели, сетевые службы и скачивание материалов не требуются.

Сборка через командную строку Blender:

```text
blender --background --factory-startup --python work/build_books.py -- --book both
```

Папка `work/` содержит также промежуточные проверки и технические превью; для использования готовых книг достаточно папок `OpenBook/` и `ClosedBook/`.

Итоговая проверка Blender и GLB: 157 успешных проверок, 0 ошибок. Полный технический отчёт сохранён в `work/validation_report.json`.
